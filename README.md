# Web Screen Block (Fabric 1.20.1)

Place a Web Screen block, right-click it, and show any website on it.

- Craft: iron/glass/redstone (III / IGI / IRI), or find it in the Functional creative tab
- Place it like a sign. The block is the screen's BOTTOM-LEFT corner; the screen grows right and up.
- Right-click: browse, type a URL, change width/height (1-8 x 1-6 blocks), nudge position
- Everyone near the screen sees it. Needs this mod on the server too; every player needs MCEF.
